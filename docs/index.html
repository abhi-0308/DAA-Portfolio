Algorithm Highlights

Here's a quick overview of some key algorithms covered in the course:

Sorting Algorithms

  • Merge Sort: Divide and conquer, stable, O(n log n)
  • Quick Sort: Pivot-based, in-place, avg O(n log n)
  • Insertion Sort: Simple, adaptive, O(n²)

Graph Algorithms

  • Dijkstra's: Shortest path, non-negative weights
  • Prim's & Kruskal's: Minimum spanning tree
  • BFS/DFS: Fundamental graph traversal

Dynamic Programming

  • 0/1 Knapsack: Item selection optimization
  • LCS: Finding common subsequences
  • Matrix Chain: Optimal order of operations

Advanced Techniques

  • Backtracking: Exhaustive search with pruning
  • Greedy Approach: Local optimal choices
  • Randomized Algorithms: Probabilistic solutions
